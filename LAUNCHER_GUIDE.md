# 🌌 COSMIC DAVIS LAUNCHER - Quick Start Guide

## How to Launch

Simply double-click or run:
```
START_COSMIC_DAVIS.bat
```

---

## Menu Options

### Training Options

**[1] 🧠 START TRAINING (Standard Autonomous Study)**
- Launches the single-mind 12D Hebbian Transformer
- Autonomous learning loop
- Opens in a new window

**[2] 🌌 START DUAL MIND TRAINING (Evolution System)**
- Launches BOTH 12D and 42D models together
- They debate every 10 iterations
- Auto-saves every 100 iterations
- Builds infinite memory
- Opens in a new window

### Monitoring & Testing

**[3] 👁️ START MONITOR (Neural Dashboard)**
- Visualizes brain activity and thoughts
- Real-time neural monitoring
- Opens in a new window

**[4] 🎭 SHOWCASE DUAL MIND (Demo)**
- Demonstrates the debate system
- See both minds in action
- Runs in current window, press any key when done

**[5] 🧪 RUN BENCHMARKS (Performance Test)**
- Tests model perplexity and speed
- Performance metrics
- Runs in current window, press any key when done

**[6] 🎵 TEST AUDIO ENGINE (Senses)**
- Verifies microphone input
- Tests audio tokenization
- Runs in current window, press any key when done

### Chat Options

**[7] 💬 CHAT with DUAL MIND (Both Together)**
- Talk to BOTH 12D + 42D simultaneously
- Watch them debate your questions
- Most powerful option!

**[8] 🗣️ CHAT with 12D ONLY (Grounded)**
- Talk to the stable, physics-based model
- Grounded in reality and structure

**[9] 🔮 CHAT with 42D ONLY (Abstract)**
- Talk to the experimental "Thinking" model
- More abstract and exploratory responses

**[0] ❌ EXIT**
- Close the launcher

---

## Tips

1. **First time users**: Try Option [4] (Showcase) first to see the system in action
2. **For conversations**: Use Option [7] (Dual Mind Chat) for the most interesting interactions
3. **For training**: Use Option [2] (Dual Mind Training) for the most advanced learning
4. **For monitoring**: Use Option [3] while training is running in another window

## Troubleshooting

If any option doesn't work:
1. Make sure you're in the correct directory
2. Check that Python is installed and in your PATH
3. Verify the `packages/cosmic-synapse-transformer` directory exists
4. Run `verify_launcher_simple.py` to check all files
