# CosmoSynapse — Quick Start

## 5 Steps to Launch

### 1. Install
```bash
cd "Cosmic Genesis A.Lmi Cybernetic Bio Resonance Core"
python install.py
```

### 2. Start the Server
```bash
python -m cosmosynapse.server
```
Server starts on **port 8765** (WebSocket).

### 3. Open Dashboard
Open `ui/cosmosynapse.html` in your browser.

### 4. With cosmos
If using with cosmos, run `START.bat → Option 2`.
The dashboard auto-connects to the Emotional API.

### 5. Verify
```bash
python install.py --check
```

---

**That's it!** The cosmic orb should be pulsing and data flowing.
